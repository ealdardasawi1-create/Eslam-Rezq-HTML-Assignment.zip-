A comprehensive mobile application UI/UX design created to connect three key pillars of the fashion and tailoring industry: fashion designers, tailors, and fabric suppliers, streamlining collaboration, material sourcing, and custom production in one platform.

Technologies Used:Figma, UI/UX Design, Wireframing, Prototyping

2. Hospital Management System (Java OOP)

A console-based hospital management system developed in Java using IntelliJ IDEA. The project applies core Object-Oriented Programming (OOP) principles—especially Inheritance and Polymorphism—to manage doctors, nurses, and patients efficiently.

Technologies Used:Java 2, Object-Oriented Programming (Inheritance), IntelliJ IDEA

3. Educational Center Database System

A relational database system designed and implemented for an educational center to manage students, instructors, courses, enrollments, and schedules. The project included designing the Entity-Relationship Diagram (ERD) and building the database tables, relationships, and queries using SQL Server.

Technologies Used:Microsoft SQL Server, ERD Modeling, Relational Database Design, SQL Queries
